An independent, interactive explainer

Bend, explained for people who have never heard of it.

Bend is a new programming language, released in September 2026. It spreads work across every core of a computer, and it only accepts a code change when the change comes with a proof that the rules people wrote still hold. These pages show both ideas with demos you can click. No programming knowledge needed.
